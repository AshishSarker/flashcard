# 🗂️ Flashcards Studio

A clean, fast, and fully offline open-source Flashcard application built for Android using HTML, Tailwind CSS, JavaScript, and Capacitor.

## ✨ Features

- **Nested Folders & Management**: Create folders to organize cards by topics with dedicated breadcrumb navigation.
- **Card Customization**: Rich card flipping (3D animations), back/front text overflow scroll support.
- **Sorting Options**: Sort folders and cards easily (Recently Added, A-Z, Z-A).
- **Import & Export**: Backup and restore your flashcards via CSV format.
- **Dark / Light Mode**: Seamless theme switching for comfortable night/day reading.
- **Privacy First**: Completely offline with all data stored locally on your device.

## 🛠️ Tech Stack

- **Frontend**: HTML5, Tailwind CSS, JavaScript (ES6)
- **Framework / Runtime**: [Capacitor](https://capacitorjs.com/)
- **Target Platform**: Android

## 🚀 Getting Started

### Prerequisites
- Node.js & npm
- Android Studio (for Android builds)

### Installation & Build

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/AshishSarker/flashcard.git](https://github.com/AshishSarker/flashcard.git)
   cd flashcard
2. Install dependencies:
   ``` npm install```
3. Sync Capacitor assets:
   ```npx cap copy```
4. Open in Android Studio:
   ```npx cap open android```
